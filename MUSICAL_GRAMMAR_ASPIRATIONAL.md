# Musical Grammar — PSY4 Phrase Generation Engine

## Overview

PSY4 does NOT use random note selection. All musical phrases are generated by a grammar engine ported from PSY3's `psy_gen.py`, using controlled mutation and tension shapes. The result is music that evolves intentionally, not chaotically.

## Architecture

```
Section (type, energy, density, tension shape)
    ↓
EvolvingSequence (16-step motif, mutates one note per N bars)
    ↓
LeadMotif (AABA structure: A, A, B contrast, A' return)
BasslineEngine (explicit BASS_PATTERNS with accents)
AcidPatternEngine (stored patterns with controlled mutation)
    ↓
Voice events → Worklet ring buffer → Sample-accurate execution
```

## Phrase Structure (AABA)

Professional psytrance uses AABA phrase structure, not endless loops:

```
Bar 0-1: A (statement)
Bar 2:   B (contrast — octave higher, different rhythm)
Bar 3:   A' (return — original with mutation)
```

**Implementation**: `LeadMotif.nextNote(step, bar, energy, rng)`
- B section (bar % 4 === 2): plays octave higher, higher density
- A sections: more sparse, recognizable motif
- Density: B = 0.7 * energy, A = 0.5 * energy

## EvolvingSequence (Controlled Mutation)

Port of PSY3's `EvolvingSequence`:

```typescript
class EvolvingSequence {
  pattern: number[] = [0];  // 16 scale degrees
  regenerate() {
    for (i = 1..16) {
      step = pick([-2, -1, -1, 0, 1, 1, 2]);
      pattern[i] = clamp(pattern[i-1] + step, -5, 5);
    }
  }
  next() {
    note = scaleNote(root, scale, pattern[pos]);
    pos = (pos + 1) % 16;
    cnt++;
    if (cnt >= 4 * 16) {
      // Mutate ONE note every 4 bars
      i = random(0, 15);
      pattern[i] = clamp(pattern[i] + pick([-2,-1,1,2]), -5, 5);
      cnt = 0;
    }
    return note;
  }
}
```

**Key principle**: Only ONE note changes at a time, every 4 bars. The motif is RECOGNIZABLE. It evolves, not randomizes.

## Bass Grammar

Explicit patterns replace `pick([0,0,2,4,7])`:

### Rolling Bass (dark-psy, forest)
```
roll-root:    [0, 0, 0, 0, 0, 0, 0, 0]  accents: [1.0, 0.7, 0.8, 0.6, 1.0, 0.7, 0.8, 0.6]
roll-walk:    [0, 0, 4, 0, 7, 0, 4, 0]  accents: [1.0, 0.7, 0.8, 0.6, 0.9, 0.7, 0.8, 0.6]
roll-passing: [0, 0, 2, 4, 7, 4, 2, 0]  accents: [1.0, 0.7, 0.6, 0.7, 0.9, 0.7, 0.6, 0.7]
```

### Offbeat Bass (progressive, morning)
```
off-root: [-1, 0, -1, 0, -1, 0, -1, 0]  accents: [0, 0.9, 0, 0.8, 0, 0.9, 0, 0.8]
off-walk: [-1, 0, -1, 4, -1, 7, -1, 4]  accents: [0, 0.9, 0, 0.8, 0, 0.9, 0, 0.8]
```

### Acid Bass (goa, acid-psy)
```
acid-1: [0, 0, 0, 4, 0, 0, 7, 0]  accents: [1.0, 0.6, 0.7, 0.8, 1.0, 0.6, 0.9, 0.6]
acid-2: [0, 4, 0, 7, 0, 4, 0, 2]  accents: [1.0, 0.7, 0.8, 0.9, 1.0, 0.7, 0.8, 0.6]
```

**Scale degrees**: 0=root, 4=fifth, 7=octave, 2=passing tone, -1=rest

## Acid Pattern Engine

Stored patterns with controlled mutation (not random `pick()`):

```typescript
class AcidPattern {
  static PATTERNS = [
    [0, 0, 4, 0, 7, 0, 4, 7],   // root-fifth-octave
    [0, 4, 7, 4, 0, 7, 4, 0],   // walking
    [0, 0, 7, 0, 4, 0, 7, 12],  // with octave
    [0, 2, 4, 7, 4, 2, 0, -1],  // descending with rest
  ];
  mutate() {
    // Change ONE step to a new degree
    i = random(0, length-1);
    pattern[i] = pick([0, 4, 7, 12, -1, 2]);
  }
}
```

## Tension Shapes

Energy/density follow musical curves, not constants:

| Shape | Formula | Use Case |
|-------|---------|----------|
| arc | `4*p*(1-p)` | Drop (peaks in middle) |
| rise | `p` | Build (rises to peak) |
| fall | `1-p` | Break (releases) |
| wave | `0.5+0.5*sin(2π*2p-π/2)` | Hypnotic (oscillating) |
| plateau | ramp up → sustain → ramp down | Steady sections |

**Section assignment**: build='rise', break='fall', drop/climax='arc'

## Density Gating

PSY3's probability gating with downbeat/offbeat accents:

```
if step % 4 == 0: probability *= 1.4   (downbeat accent)
if step % 2 == 1: probability *= 1.15  (offbeat accent)
```

This creates the "driving" feel — downbeats get 40% more events, offbeats 15% more.

## Arrangement Structure

Multi-section arrangement (not loop-based):

```
INTRO (8 bars, energy 0.3, density 0.3)
  → GROOVE (8 bars, energy 0.6, density 0.6)
  → BUILD (8 bars, energy 0.7, density 0.6, tension=rise)
  → DROP (16 bars, energy 1.0, density 0.9, tension=arc)
  → BREAK (8 bars, energy 0.2, density 0.25, tension=fall)
  → DROP (16 bars, energy 1.0, density 0.9)
  → CLIMAX (16 bars, energy 1.0, density 1.0)
```

**Section contrast**: Not just volume. Each section changes:
- Instrument density (which voices play)
- Filter state (cutoff, resonance)
- FX density (reverb/delay send amounts)
- Stereo width
- Sidechain depth
- Bass behavior (off in break, rolling in drop)

## Variation Rules

1. **Never random chaos**: All variation uses seeded RNG
2. **Controlled mutation**: One note changes at a time, at phrase boundaries
3. **Recognizable identity**: Motif is preserved; it evolves, not randomizes
4. **AABA structure**: Contrast (B) then return (A') — not endless A loops
5. **Section-aware**: Different sections have different density, energy, FX

## Performance Rules

1. **Downbeat accent**: Steps 0,4,8,12 get higher velocity
2. **Offbeat lightening**: Steps 1,3,5,7 get 85% velocity
3. **Ghost notes**: Low velocity (0.2), short duration, on odd-bar downbeats
4. **Fills**: Steps 12-15 of phrase-end bars (4-bar phrases)
5. **Swing**: Offbeat microtiming `+ swing * s16` (controlled, not random)
