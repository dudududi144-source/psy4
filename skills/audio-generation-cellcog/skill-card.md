This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and content creators use this skill to ask an agent to generate speech, voiceovers, cloned/avatar voices, sound effects, and music through CellCog. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill supports cloned/avatar voices, which can be misused for deceptive impersonation. <br>
Mitigation: Use cloned or avatar voices only for voices you own or have explicit permission to use, and avoid deceptive, fraudulent, or impersonation-oriented uses. <br>
Risk: The skill requires a CellCog API key for audio generation. <br>
Mitigation: Install and configure it only when you intend to use CellCog, and manage CELLCOG_API_KEY as a secret. <br>
